# Phonebook Assistant

A streamlined, modern web-based contact management application designed to organize, search, and manage personal and professional contacts efficiently.

## 📌 Features

* **Contact Management**: Easily add, view, update, and delete contact details.
* **Instant Search & Filter**: Quickly locate contacts by name, email, phone number, or custom tags.
* **Interactive UI**: Clean, responsive layout with intuitive navigation for fast user operations.
* **Import / Export Support**: Backup and restore contact records via standard format files (JSON/CSV).
* **Single-File Architecture**: Compact and self-contained web design for effortless deployment and lightweight operation.

## 🚀 Quick Start

### Prerequisites

All you need is a modern web browser (Google Chrome, Mozilla Firefox, Safari, or Microsoft Edge).

### Running the Application

1. **Clone or Download** this repository:

   ```bash
   git clone https://github.com/your-username/phonebook-assistant.git
   cd phonebook-assistant
   ```

2. **Open the App**:
   Simply double-click the `index.html` file or open it directly inside your web browser.

## ❓ Sample Usage & Questions

Below are example queries and actions you can use when interacting with or searching through the Phonebook Assistant:

* **Basic Search:** *"Find John Smith's phone number"* or *"Search for contacts tagged 'Work'"*
* **Contact Lookup:** *"What is the email address for Sarah Connor?"*
* **Category Filtering:** *"Show me all contacts under the 'Engineering' department."*
* **Data Management:** *"How do I export my current contact list to a CSV file?"*

## 💡 Usage Guide

1. **Adding a Contact**:
   * Click on the **"Add Contact"** button.
   * Fill in details such as First Name, Last Name, Phone Number, Email, and Category/Notes.
   * Click **Save**.

2. **Searching**:
   * Type any keyword into the top search bar to immediately filter the contact list.

3. **Editing / Deleting**:
   * Select any contact card to view details.
   * Click **Edit** to modify information or **Delete** to remove the entry.
